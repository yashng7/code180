# 01 · Arrays & Hashing

Hash maps for counting, lookups and grouping; prefix/suffix tricks on arrays.

| # | Problem | Difficulty | Status |

| 1 | Contains Duplicate | Easy | ✅ |
| 2 | Valid Anagram | Easy | ✅ |

| 5 | Top K Frequent Elements | Medium | ✅ |
| 6 | Encode and Decode Strings | Medium | ✅ |
| 7 | Product of Array Except Self | Medium | ✅ |
| 8 | Valid Sudoku | Medium | ✅ |
| 9 | Longest Consecutive Sequence | Medium | ✅ |

**Key patterns:** frequency map, `seen` set, grouping by key, prefix/suffix products.

All nine problems ship visualizations: a terminal animation
(`python3 run.py <problem> --animate`) and a 3blue1brown-style HTML page
(`python3 run.py <problem> --html`).
