# 03 · Sliding Window

Maintain a contiguous window while expanding/shrinking it in `O(n)`.

| # | Problem | Difficulty | Status |
| --- | --- | --- | --- |
| 1 | Best Time to Buy and Sell Stock | Easy | ✅ |
| 2 | Longest Substring Without Repeating Characters | Medium | ✅ |
| 3 | Longest Repeating Character Replacement | Medium | ✅ |
| 4 | Permutation in String | Medium | ✅ |
| 5 | Minimum Window Substring | Hard | ✅ |
| 6 | Sliding Window Maximum | Hard | ✅ |

**Key patterns:** variable-size window, fixed-size window, monotonic deque.
